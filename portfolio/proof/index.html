Cooldown logic

EXAMPLE

A tiny, deterministic module demonstrates how timing logic can stay independent of the UI and networking. This is a newly written illustration, not a published production module.

examples/Cooldown.luau
-- Illustrative architecture example, not client code.
local Cooldown = {}

function Cooldown.canUse(lastUse, now, duration)
    return lastUse == nil or now - lastUse >= duration
end

function Cooldown.remaining(lastUse, now, duration)
    if lastUse == nil then
        return 0
    end

    return math.max(0, duration - (now - lastUse))
end

return Cooldown
